# 안산 청년 혜택 알리미 (데모)

AI+X 공학융합프로젝트 · 백창욱 팀

안산에 사는 청년이 생년월일과 안산 전입일을 넣으면, 안산시 청년 사업 52건의 **거주·나이 조건**을 공고문 기준으로 판정해서 받을 수 있는 혜택만 보여주는 모바일 웹 데모입니다.

**데모 주소:** https://chang-kyu.github.io/aix-teamplay/

## 무엇을 보여주나

- 온통청년은 '관심 지역' 하나만 받습니다. 이 데모는 **전입일·거주기간·생활권(학교·직장)**까지 받아서 거주 요건을 판정하고, 안 되면 **언제부터 / 무엇을 하면 되는지** 알려줍니다.
- 결과는 5가지로 나뉩니다: 충족 · 전입신고하면 충족 · YYYY-MM-DD부터 충족 · 확인 필요 · 미충족
- 판정 근거가 된 공고 원문 문장과 안산시청 출처 링크를 함께 보여줍니다.
- 입력값은 브라우저(localStorage)에만 저장합니다. 로그인·서버가 없습니다.

## 폴더

| 경로 | 내용 |
|---|---|
| `index.html` | 배포되는 웹 데모 (데이터 + 판정 엔진이 한 파일에 들어 있음) |
| `src/judge.js` | 판정 엔진 (의존성 없는 JS, 브라우저/Node 공용) |
| `src/input_schema.json` | 입력 화면 정의 (필드, 조건부 표시, 예시 프로필) |
| `src/build_v3.py` | 정책 52건 원본 데이터 → `policies_v3.json`, CSV 생성 |
| `src/policies_v3.json` | 프론트엔드용 정책 데이터 |
| `src/ansan_policies_v3.csv` | 검토용 표 |
| `src/test_judge.mjs` | 페르소나 테스트 |
| `src/web/` | 웹 데모 템플릿과 빌드 스크립트 |
| `docs/` | 판정 규칙·입력 정보·데이터 구조 설계 문서 |

## 거주 요건 유형

| 코드 | 의미 | 건수 |
|---|---|---|
| R1 | 안산 주민등록 | 13 |
| R2 | 안산 거주기간 (연속 3년 또는 합산 10년 등) | 6 |
| R4 | 안산 주민등록 + 경기도 거주기간 | 1 |
| R6 | 안산 주민등록 또는 안산 소재 학교·직장·사업장 | 4 |
| R7 | 거주 무관 | 26 |
| R8 | 경기도 거주 | 1 |
| R10 | 안산 외 지역 거주자만 | 1 |

## 수정하고 다시 배포하기

```bash
cd src
python build_v3.py          # 데이터 수정은 build_v3.py 안의 목록에서
node test_judge.mjs         # 판정 결과 확인 (Node 18+)
python web/build_web.py     # web/index.html 생성
cp web/index.html ../index.html
```

루트의 `index.html`을 커밋하면 1~2분 뒤 데모 주소에 반영됩니다.
