# 마감 공고 분리 + 신청 링크 안내 (2026-11-24)

> 11/18 화면(10 문서)에 두 문제를 고쳤다. AI 챗봇은 다음 단계.

## 1. 문제와 원인

| 문제 | 원인 |
|---|---|
| 신청하러 가기 → 로그인 화면 → 공고로 안 넘어감 | `apply.url`이 잡아바·경기민원24·고용24·복지로·LH 등 사이트 **첫 화면 주소**뿐. 로그인하면 메인으로 돌아감. 공고별 직접 링크(딥링크)가 없음. 안산시청 공고 원문(`sourceUrl`)은 로그인 없이 열림 |
| 모집 마감된 공고가 계속 뜸 | 결과 화면이 모집 상태와 관계없이 전부 표시 (마감은 정렬만 뒤로). 도현 예시 기준 52건 중 35건이 마감인데 '충족'에 섞여 있었음 |
| 지난 모집이 '공고 확인'으로 뜸 | ANS006·ANS009·ANS033은 날짜 없이 안내 문구만 있어서 마감 판정이 안 됨 |

## 2. 고친 것

**신청 링크 (template.html)**
- 외부 신청 사이트면 안내 상자: ① 로그인 ② 검색창에 사업명 검색 ③ 못 찾으면 안산시청 공고 원문
- 주 버튼 "검색어 복사하고 ○○ 열기": 누르면 사업명(괄호 설명 뺀 짧은 이름)을 클립보드에 복사 + 새 탭으로 사이트 열기
- 보조 버튼 "안산시청 공고 원문 보기" 항상 표시
- 신청 방법 탭 '신청하는 곳'에 사이트 이름 + "로그인 필요" 표시 (`SITES` 표)

**마감 공고 (template.html, judge.js)**
- 결과 목록·요약 카드 숫자·필터 개수에서 마감 사업 제외
- 맨 아래 접힘 영역 "모집 마감 N건": 판정 배지 + 마감일 + 다음 모집 안내(`periodText`)
- 필터 칩 '모집 마감' 추가
- 상세 화면: 마감이면 "이번 모집은 ○○에 마감됐어요" 상자 + 공고 원문 버튼만
- `recruitState`: 마감일만 있는 공고도 마감일이 지나면 closed

**데이터 (build_v3.py)**
- ANS006 대학생 아이디어 공모전 2026-05-01~10-31, ANS009 스타트업 창업경진대회 2026-04-01~05-31, ANS033 청년 노동자 통장 2026-08-01~08-31 — 모두 안내 문구 기준 **추정** 날짜 (periodText에 표기)
