## 3. 코드가 아니라 사람이 정한 부분

- **R 코드 붙이기**: 사업마다 공고 원문을 읽고 사람이 R 코드를 붙였다. 판단 근거 문장은 CSV의 `evidence_text`(v3는 `evidence`) 열에 있다. 코드는 붙여 둔 R 코드로 판정만 한다.

## 4. 실행 방법

Python 3 + pandas, Node 22 이상. 이 폴더(README가 있는 곳)에서:

```bash
# 거주요건 판정: v2 75건 (스크립트 안의 기준일 2026-10-02)
(cd data && python ../code/residence_judge.py)

# 거주요건 판정: v1 51건
(cd data/v1 && python ../../code/residence_judge.py)

# v3 데이터 생성 → 판정 엔진 테스트 (테스트 기준일 2026-11-01)
(cd code/v3 && python build_v3.py && node test_judge.mjs)
```

- `build_v3.py`는 실행한 폴더에 `policies_v3.json`(웹 화면이 읽는 파일)과 `ansan_policies_v3.csv`를 만든다.
- `collect_ansan_youth.py`는 안산시청 사이트에 직접 접속한다(requests, beautifulsoup4 필요). 작성 당시 Claude 환경에서는 안산시청 접속이 막혀 있어 실행해 보지 못한 코드다.
