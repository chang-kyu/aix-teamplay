# 출처: 안산시청 https://www.ansan.go.kr/www/common/bbs/selectBbsDetail.do?key=271&bbs_code=WWW13&bbs_seq=1666698
# 수집일: 2026-11-25

안산시의 우수한 관광자원을 널리 홍보하고 체류형 여행 분위기 확산을 위해 실시하는 「2026년 안산에서 살아보기」 참가자를 아래와 같이 모집하오니, 많은 관심과 신청 부탁드립니다.
1. 공고기간 : 2026. 3. 17.(화) ~  4. 17.(금)
2. 접수기간 : 2026. 4.  1.(수) ~  4. 17.(금)
3. 여행기간 : 2026. 5.  1.(금) ~ 11. 30.(월) 중 2박 3일 ~ 3박 4일 체류
4. 모집대상 및 신청서식 : 붙임 공고문 참고
붙임  2026년 안산에서 살아보기 공고문 1부.  끝.
